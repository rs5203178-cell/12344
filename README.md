# Jaadu — Luxury Pinterest Dreamland

A React + Vite birthday experience with a soft coquette / editorial scrapbook aesthetic.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## What's inside

- Cinematic envelope-style opening and editorial scrapbook layout
- Personal recorded shayari player (`public/audio/jaadu-shayari.mp3`)
- Official YouTube embed for “Hawayein”
- Long-distance note, Open When letters, and interactive wish jar
- Animated birthday cake, candle-blowing celebration, and final surprise
- Extra sealed postscript note with a reveal interaction
- Responsive mobile styling and reduced-motion support

The song is streamed from YouTube; it is not bundled with the project. Replace the Unsplash image URLs in `src/main.jsx` if you want to use other visuals.
